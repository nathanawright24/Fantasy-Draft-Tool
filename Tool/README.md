# 2026 Live Draft Tool

Live draft support for a 12-team full-PPR redraft league. Build the data layer with
`python build/pipeline.py`, then run the app with
`streamlit run app/main.py`. **Start with `markdowns/SPEC-draft-tool-build.md`** in the
parent `Fantasy/` workspace — it is the authoritative build spec (folder layout,
valuation model, availability model, guardrails) and supersedes anything below.
